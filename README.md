# Project brief: Heathrow Airport Management System

The following design brief was generated by ChatGPT.

Project: Fictional Heathrow Operations
Ruby · SQL · Terminal CLI · GitHub

```A fictionalised London airport management system inspired by Heathrow. It manages flights, passengers, airport staff, facilities and day-to-day operational activity.```

## Business problem
An airport is more than a collection of flights. It is a complex operation involving aircraft movements, passenger bookings, staff schedules, terminal facilities and operational constraints.

Our fictional airport currently relies on separate records to manage these activities. This makes it difficult to answer basic operational questions:
- Which passengers are booked on a particular flight?
- Which gates are allocated to departing flights?
- Are two flights scheduled to use the same gate at overlapping times?
- Which staff members are working a particular shift?
- How many seats remain available on a flight?
- Which rooms or facilities are available for operational use?
- Which flights have been delayed, cancelled or completed?

Your application will provide a centralised database and a terminal-based interface for managing and querying this information.

## Project objectives
1. Design a properly normalised relational SQL database.
2. Build a Ruby command-line application using standard Ruby and a database adapter.
3. Support creating, reading, updating and deleting appropriate records.
4. Implement business rules that prevent invalid operational decisions.
5. Demonstrate meaningful SQL queries involving joins, aggregations, filtering and subqueries.
6. Use Git and GitHub to document development and demonstrate a professional workflow.

## Scope
Included in the first version
- Passengers and flight bookings
- Flights, aircraft and airlines
- Airport gates and terminal rooms
- Staff, departments and shift assignments
- Flight status and operational changes
- Capacity checks and basic conflict detection
- Useful management reports


## Deliberately excluded
- Real-time flight feeds
- Actual ticket payments
- Live aircraft tracking
- Airline reservation integrations
- A graphical interface or website
- Complex air traffic control or baggage handling
